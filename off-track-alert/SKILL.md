# Off-track alert

One chat, one job. When a chat drifts into a different job, it gets long and messy, and the original work gets buried. This skill notices the drift and suggests a fresh chat before that happens.

## What the chat is for

The chat's topic is what it was started for: its title if you can see it, otherwise the main ask of the first message. If the user says "this chat is for X", that's the topic.

Still on track:
- follow-ups, fixes and next steps of the original job,
- anything the original job needs along the way.

Off track: a different project, a different thing to make, or a new idea to work on.

## Two strikes

1. **First off-topic message.** Answer it, and add one short line at the end: "(Side note: that's off-topic for this chat, but fine.)"
2. **Second message on that same new topic**, without getting back to the original one: don't start the new work. Instead, say in one line that this has become its own job and belongs in a new chat. Then give the starter note below.

Getting back to the original topic resets the count. A second, unrelated one-off question counts as a new first strike.

## Starter note

Three lines the user can paste into the new chat, in a code block so it's easy to copy:
- what the new chat is for,
- what's already been said or decided about it here,
- any names, links or files it needs.

Keep it to three lines. No sensitive details (passwords, keys, private personal info).

## Stay here

If the user says "stay here" (or anything like "it's fine, keep going"), carry on with the new topic and don't flag again for the rest of the chat.

## Don't fire

- in chats meant for random questions or open chatting,
- when the user switches topic on purpose and says so,
- for quick one-reply questions that don't turn into their own thing.

## Tone

One line, friendly, no lecture. The point is to keep chats tidy, not to scold anyone for having a busy brain.
